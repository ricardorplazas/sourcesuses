# Governance records

This directory contains the operating boundaries and review records required before Sources & Uses becomes a commercial product.

- `founder-boundary.md` — separation from employment and confidential information;
- `content-provenance-policy.md` — permitted sources, review, and release controls;
- `professional-review-checklist.md` — questions requiring qualified advice;
- `brand-clearance-log.md` — name and affiliation checks;
- `content-provenance-register.csv` — template for item-level source records;
- `phase-0-status.md` — completion and blocker register.

These files are controls and working records, not legal or tax advice. An unchecked professional-review item must not be represented as cleared.
