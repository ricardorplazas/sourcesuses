# Phase 1 validation operations

This directory turns Phase 1 into an evidence-collection process. It does not treat built pages, sign-ups or compliments as product-market validation.

## Source of truth

- `phase-1-status.md`: what is built, blocked and measured.
- `experiment-register.csv`: hypotheses, thresholds and decisions.
- `weekly-scorecard.csv`: qualified traffic, funnel, orders, quality and founder time.
- `interview-guide.md` and `interview-log.csv`: problem evidence.
- `partner-outreach.csv`: dated distribution actions and tracked traffic.
- `event-taxonomy.md`: minimal events and consent boundaries.
- `email-sequence.md`: consent-aware copy ready for a provider.
- `operations-runbook.md`: launch, weekly review and gate procedure.

Never insert confidential employer information, real candidate submissions or sensitive personal data. Use participant IDs rather than names in the repository.
