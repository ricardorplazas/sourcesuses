# Phase 1 operations runbook

## Before opening traffic

1. Run `npm ci && npm run verify` in the public repository.
2. Run `npm run verify` in `../sourcesuses-private`.
3. Confirm the public URL and test diagnostic completion on desktop and mobile.
4. Complete employment/IP, privacy/contact and brand gates.
5. Configure a form endpoint only after its data-processing and retention terms are accepted.
6. Exclude founder/test traffic from the weekly scorecard.

## Interview gate

Run 12+ interviews before committing additional case-production time. Proceed only if repeated full-case rehearsal pain appears and at least half used or paid for structured preparation.

## Weekly review

Update `weekly-scorecard.csv`, founder hours and cash cost. Review funnel by source and message variant. Do not optimise to raw visits or email sign-ups.

## Checkout gate

Do not accept non-refundable payment until Case 01 is a complete audited release candidate. If using a refundable deposit, state delivery date, refund rights and what does not yet exist.

## Phase gate

Hold a written decision after the thresholds in `experiment-register.csv`. Permit one focused product/message correction if the gate fails. Do not respond to failure by building accounts, the production viewer or add-in.
