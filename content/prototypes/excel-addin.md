---
title: Excel add-in concept test
description: A clickable concept test for five interview-focused Excel formatting and model-cleanup commands.
---

This mock-up tests whether an interview-focused formatting tool changes bundle preference. It is not Office.js, does not access a workbook and is not included in the proposed CHF 59/79 case.

The five commands represent the proposed minimum feature set: colour coding, finance number formats, total styles, model standardisation and a submission checklist. Production development remains behind a separate paid-demand and compatibility gate.
