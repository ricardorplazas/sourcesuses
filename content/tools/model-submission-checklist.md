# Model submission checklist

Print this page or copy it into your case work plan.

## Mechanics

- [ ] Sources equal uses
- [ ] Enterprise value bridges to purchase equity value
- [ ] Cash flow reaches debt repayment
- [ ] Debt roll-forward and interest reconcile
- [ ] Exit enterprise value bridges to sponsor proceeds
- [ ] MOIC and IRR/XIRR use consistent signs and dates
- [ ] Sensitivities move in the expected directions

## Decision consistency

- [ ] Base and downside assumptions match the narrative
- [ ] Memo/deck numbers match the final model
- [ ] Recommendation states conditions and decision-changing evidence
- [ ] Risks have a quantified or clearly described consequence

## File hygiene

- [ ] Inputs and formulas follow one colour standard
- [ ] Units, signs, decimals and zero display are consistent
- [ ] No accidental external links, comments or author metadata
- [ ] Hidden sheets/rows/columns were deliberately reviewed
- [ ] Filename and version are submission-ready
- [ ] Workbook opens without repair warnings

This checklist reduces avoidable errors; it does not replace an independent formula review.
